
# 🚀 Muhammad Shah Nawaz : Personal Developer Portfolio

A modern, responsive, and high-performance developer portfolio website built with **React**, **Vite**, **Tailwind CSS v4**, and **Framer Motion**.

---

## ✨ Features

- 🎨 **Modern Dark Aesthetic**: Sleek `slate-950` theme with glowing cyan & violet accents, glassmorphic elements, and micro-animations.
- ⚡ **Fast & Responsive**: Powered by Vite and Tailwind CSS v4 for ultra-fast load times and full responsiveness across mobile, tablet, and desktop devices.
- 📱 **Smooth Navigation**: Multi-page routing powered by `react-router-dom` v7 with active link highlights and mobile navigation drawer.
- 📂 **Interactive Projects Showcase**: Filterable project gallery with live search by category (`C++`, `Python`, `Java`, `Web`, `Mobile`, `Other`), direct GitHub links, and asset preview images.
- 🛠️ **Categorized Tech Stack**: Interactive skills matrix organized across 7 tech domains with proficiency badges and native SVG/PNG logos.
- 🎓 **Education & Experience Timeline**: Interactive overview of academic background (BS Software Engineering at FAST-NUCES) and technical interests.
- 📬 **Contact Hub**: Direct contact info cards with instant copy-to-clipboard functionality and a pre-configured email message generator.

## 💻 Getting Started Locally

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/mshahnawaz1202/PortFolio.git
   cd PortFolio/Portfolio
   ```
2. **Install dependencies:**

   ```bash
   npm install
   ```
3. **Start the development server:**

   ```bash
   npm run dev
   ```
4. **Build for production:**

   ```bash
   npm run build
   ```
